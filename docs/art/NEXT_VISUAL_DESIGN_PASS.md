# 3Fareet — Next Visual Design Pass

Scope: visual/art direction only. APK/build work is intentionally out of scope for this pass.

## Art direction
- Cairo supernatural street-racing fantasy.
- Primary palette: near-black asphalt, electric purple spirit energy, cyan navigation/readability light, warm gold hero accents.
- Keep the Hero Car as the highest-contrast object in gameplay shots.
- Avoid generic cyberpunk clutter: every prop should feel Cairo/Egypt-inspired or racing-functional.

## Priority design tasks
1. Hero Car silhouette pass
   - Sharper front light signature.
   - Stronger rear spirit exhaust identity.
   - Gold accent used sparingly around focal aero details.
   - Preserve gameplay collider/vehicle dimensions.

2. Cairo track landmarks
   - Add readable skyline silhouettes: minaret/dome clusters, distant pyramid forms, bridge/gantry motifs.
   - Build landmark rhythm so each track sector has a distinct visual memory.
   - Keep collision-free decorative geometry outside the driving corridor.

3. Road language
   - Spirit rune lane markers at major turns.
   - Purple/cyan hazard blades for edge readability.
   - Gold only at start/finish and premium focal moments.

4. Drift/Nitro identity
   - Drift: gold core with purple decay.
   - Nitro/Spirit: purple core transitioning to cyan at peak intensity.
   - Effects must remain readable without covering the rear silhouette.

5. HUD polish
   - Maintain compact black glass panels.
   - Position/time/speed remain primary information.
   - Spirit meter should visually charge toward gold near maximum energy.
   - Avoid adding permanent UI that blocks the road.

6. Start sequence
   - Dark pre-start frame.
   - Purple countdown pulses.
   - Gold/cyan GO impact.
   - Start gate should frame the Hero Car rather than compete with it.

7. Finish spectacle
   - Strong gold crown/gate focal point.
   - Purple/cyan supporting lights.
   - Keep finish readability clear at racing speed.

## Mobile visual constraints
- Favor large silhouettes over tiny details.
- Avoid dense transparent particle layers and expensive full-screen effects.
- Decorative props must not add gameplay colliders.
- Keep road edges readable on small displays and during nitro.

## Acceptance shots for the art pass
- Hero Car idle/start-line 3/4 rear.
- Countdown/GO frame.
- High-speed Cairo straight with skyline landmark.
- Drift corner with trail readable against asphalt.
- Nitro frame showing Spirit color transition.
- Finish-gate approach.

## Next implementation order
`Hero silhouette -> Cairo landmarks -> road language -> VFX refinement -> HUD refinement -> start/finish presentation -> visual QA`
