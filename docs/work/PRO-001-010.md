## Architecture notes

The fixed-step runner is now the deterministic simulation clock boundary. Vehicle physics, drift, race state, AI and later client prediction/reconciliation must consume fixed simulation steps instead of inventing independent frame timing.

`GameInputSnapshot` is deliberately transport-neutral. The same intent model can feed local touch controls now and later become the normalized command payload for multiplayer prediction/reconciliation without coupling gameplay to Flutter widgets.

Android platform files are generated deterministically from the pinned Flutter 3.44.0 template by `tool/bootstrap_android.*`. This avoids committing a stale platform template before Android build/release tasks PRO-013/PRO-014 own that surface.
