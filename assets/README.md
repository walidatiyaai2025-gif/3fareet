# Runtime Assets

Expected runtime directories:

- `cars/`
- `tracks/`
- `environment/`
- `vfx/`
- `audio/music/`
- `audio/sfx/`
- `ui/`
- `placeholders/`

See `docs/ASSET_PIPELINE.md` for naming and promotion rules. Directories are created as assets are added; do not commit empty binary placeholders solely to keep folders alive in Git.
